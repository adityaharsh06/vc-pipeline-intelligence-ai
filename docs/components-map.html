Components · responsibilities, data flow and ownership

All AI tasks use Gemini Flash (gemini-3.8-flash → 3.7-flash → flash-latest → 3-flash-preview fallback).
No other model or LLM provider is used.
#ComponentImplementationResponsibility

2Refresh nowPOST /api/runOn-demand scan for the evaluator. Public by design (no login), rate-limited by a 5-minute cooldown.

5Bing News RSSlib/sources.tsSecond live news source with direct article URLs, so signals link straight to the publisher.

7Gemini Flash classifierlib/gemini.ts · JSON schemaOne call per 8 investors. Decides if each item is really about the investor (rejects same-name people and passing mentions), signal type, relevance to B2B logistics SaaS (0–100), same-event grouping, a why-now note and an opening line.

One run, step by step

  1. Cron (1) or Refresh now (2) starts a run; the orchestrator (3) fingerprints the 🔒 columns.
  2. For 8 investors at a time, query Google News (4) and Bing News (5) live: 4 searches per investor.
  3. Drop duplicates and anything older than 30 days (logged as rejected).
  4. One Gemini Flash call (7) classifies the whole batch.
  5. Merge articles about the same event; scoring rules (8) pick the strongest signal.
  6. Write the 4 signal columns via vc_apply_signal (9); store full evidence in audit tables (12).
  7. If every source fails for an investor, leave its row unchanged. A failure never counts as "quiet".
  8. Repeat until all 50 are done, handing off to a new invocation when needed; then fingerprint again and record ✓ untouched.
